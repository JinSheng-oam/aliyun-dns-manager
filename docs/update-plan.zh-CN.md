## 下一步执行建议

先完成 `v0.6.0` 发布闭环：

1. 创建 `v0.6.0` 标签并推送，由 Release workflow 自动发布
2. 确认 Release workflow、Docker 构建和发行包内容检查通过

- Docker 部署能最快提升安装转化
